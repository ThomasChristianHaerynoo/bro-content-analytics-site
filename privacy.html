Privacy Policy

Bro Content Analytics is operated by Thomas Christian Haeryono, an individual developer. The tool is still under development, so this policy describes its intended behavior.

Data flow

  1. The account owner signs in through TikTok's official Login Kit and approves the requested permissions.
  2. The tool receives an authorization code on a local redirect address on the owner's own computer (http://127.0.0.1:3455/callback/) and exchanges it for an access token.
  3. The tool calls the TikTok Display API to fetch the owner's public video data.
  4. The data is processed locally into Excel and PDF reports.

The tool is intended to run on the operator's own computer. This website only provides information; it has no login, forms, or analytics collection.

Data collected

Through the Display API, the tool retrieves basic profile information and, for the owner's public videos, details such as title or description, publish time, and counts of views, likes, comments, and shares. The tool requests the TikTok scopes user.info.basic and video.list. These scopes have been requested but are not confirmed as approved by TikTok. The exact fields available depend on what TikTok grants.

OAuth credentials

The app's client key and client secret are kept in a local .env file, and access tokens are kept in a local .secrets/ folder. Both are excluded from version control and from this website. This policy makes no claim that these files are encrypted.

Storage

Raw API responses, cleaned data, and generated reports are stored as files on the owner's computer. They are not uploaded to any server operated by this project. The tool is not designed to upload this data anywhere.

Retention

The tool does not delete data automatically. Local data, tokens, and reports remain on the computer until the owner manually deletes them.

Deletion

To delete saved data, manually delete the files in the project's data/raw/, data/cleaned/, reports/excel/ and reports/pdf/ folders. To delete saved tokens, delete the files in .secrets/. To remove the app credentials, delete the .env file. Also delete any copies you made elsewhere (backups, cloud sync, emailed reports).

Revoking access

The owner can revoke the tool's access in TikTok's app settings (security and permissions / connected apps; exact menu names may vary). After revoking, the tool can no longer retrieve data, and stored tokens should be deleted.
